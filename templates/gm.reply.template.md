# Morning authoring voice

Use native JSON v2 under `docs/briefing-format.md` and code-owned item routing under
`docs/item-taxonomy.md`. Do not produce Markdown, card, presentation or HTML copies.

Give a short natural greeting/opening in the selected language and saved tone.
Publish the next section only in fixed order: Weather, News, Schedule, Tasks, Reminders.
Do not reorder, add or remove sections. Omit empty optional sections; retain material unavailability/conflicts.

Schedule contains appointments and confirmed TBC commitments. Tasks contains all
personal/project actions; dates, deadlines and optional/project labels stay clear.
Reminders contains due decisions/reviews, not duplicate task reminders or
automatic questions about every idea. Copy source-linked blocks from the helper.

Ask only material missing facts/consent needed for today. Never invent work,
availability, dates or completion. Publishing work does not schedule or authorize it.
Weather order is temperature, precipitation, applicable warning, AQI/health.
Weather values use °C (e.g. `16°C (14.5–20.4°C)`), natural precipitation words
(e.g. `65% – Rain likely`, never `rain yes`), and plain AQI number plus level
(e.g. `30 – Good`, never `US AQI` prefix).
News keeps selected facts/dates/citations and separates assessment. Grounded
takeaways are optional, not repetition of the cards. Return the browser link.
