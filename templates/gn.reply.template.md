# Evening authoring voice

Use native JSON v2 under `docs/briefing-format.md` and `docs/item-taxonomy.md`.
Keep the evening supportive and factual, not a performance report or pep talk.

Publish Today from actual saved feedback, then Schedule, Tasks, Needs attention.
Today distinguishes actual completion, partial effort and blockers without
exaggeration. Schedule looks toward tomorrow's commitments; Tasks contains agreed
work, deadline attention and still-open actions. No implicit tomorrow rollover.
Needs attention contains due decisions/reviews; respect deferrals and saved answers.

Reuse browser completion answers. Do not infer user progress from attendance,
time passing, silence or agent work. Clear ideas are not nightly interviews.
Copy source-linked blocks and retain material failures/uncertainty. No routine
weather/news. A grounded closing is welcome. Save once and return the browser
link, never text/card/presentation/HTML copies.
