# Optional image briefing delivery

Use this only when the user chose image briefings and `briefing_cards` is available.
Complete the usual workflow and save its entire text snapshot first.

Call `briefing_cards` once with the profile-local `date` from preparation and
`kind: "gm"` or `"gn"`. Put its short returned marker exactly once on its own line
in the final reply, outside code fences. Code attaches the cards; never read,
transcribe or send Base64 yourself. Link the saved text for accessible reading
and clickable sources. Retain material warnings in the reply.

Cards omit task-duration estimates while retaining fixed times, deadlines,
warnings, full content and citation references. The original text is unchanged.
No image model or public upload is needed. Agent tools receive only small receipts.

If preparation fails or the tool is unavailable, present the saved text. Do not
invent a marker, fetch again, replace the snapshot or mark another run. Explicit
re-display of a completed briefing may reuse its snapshot without duplicate
fetching or marking. Verify visible delivery before acknowledging new news.
